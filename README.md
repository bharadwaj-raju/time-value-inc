# Time Value Inc.

An entry for the September 2026 PyWeek challenge "Borrowed Time" (https://pyweek.org/42/).

Entry: https://pyweek.org/e/asecondshort/

The game is entirely keyboard-based, so please use arrow keys for movement, and the in-game indicated keys for various features.

## How to Run

If you're using `uv`, just run `uv run run_game.py`.

Otherwise:

### Linux/macOS/UNIX

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run_game.py
```

### Windows

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run_game.py
```
