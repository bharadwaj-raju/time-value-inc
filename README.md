# How to Run

If you're using `uv`, just run `uv run run_game.py`.

Otherwise:

## Linux/macOS/UNIX

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run_game.py
```

## Windows

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run_game.py
```
